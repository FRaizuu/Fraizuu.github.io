# Beautifully Unsorted — Fa’iz Portfolio

Static portfolio by Muhamad Fa’iz Al Akbar.

## Publish
1. Extract this ZIP.
2. Upload index.html, style.css, app.js, projects.json, and .nojekyll to the root of FRaizuu/Fraizuu.github.io on main. Replace index.html when asked. Keep any unrelated repository files.
3. In repository Settings > Pages, choose Deploy from a branch, main, /(root), then Save.
4. Wait for the Pages deployment to complete in Actions.
5. Open https://fraizuu.github.io/.

No build step or dependencies are required. The design loads its fonts from Google Fonts.

Older script.js and styles.css files are not used by this version and can be retained.
